## Open items

What is waiting, for whom, and since when: an unanswered ask, a step only the owner can do, output the owner will paste.

## Decisions

Newest first. Each entry has this form:

```text
### <date>, <stage>.<n>: <the ask>
Choice: <the option taken, or "open">
Decided by: <owner | owner, delegated to the agent | open>
Reason: <the owner's words; "letter only" or "not given" if there were none>
Evidence the agent showed: <file paths or command output>
Not verified: <what could not be run or seen, or "nothing">
```

A follow-up takes a letter (`0.3b`). An ask the stage file does not list takes the next free number in its stage. A decision taken when resuming is numbered `R.<n>`. Where the repository keeps its own piece in place of a template piece, record which stands for which.
