# ASDLC adoption decisions

Every decision the owner took while this repository was prepared, newest first. A new session reads this file and the scorecard before it continues.

Each entry has this form:

```text
## <date>, decision <stage>.<n>: <the question>
Choice: <the option taken>
Decided by: <owner | delegated to the agent>
Reason: <in the owner's words>
Evidence the agent showed: <file paths or command output>
```
