# reference

Documents kept as received: market research, pricing, a roadmap, a partner's requirements. They are background for the decisions in [decisions/](../decisions/), not rules. A spec never cites them as the reason for a rule; the decision record that came from them does.

Add a document here unchanged, with the date it was received at the top. When it is replaced, keep the old version next to the new one rather than editing it.
